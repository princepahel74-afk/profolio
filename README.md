# Prince Pahel — Cyberpunk & Gamer Portfolio

A modern, high-octane personal developer portfolio engineered with a cyberpunk gaming aesthetic, interactive playable canvas mini-game, real-time FPS/ping telemetry HUD, and synthesized 8-bit audio effects.

## 🚀 Features

- **Gamer Aesthetic & UI**:
  - Sci-fi color palette (Neon Cyan, Pink, Emerald, Yellow, Purple).
  - Chamfered polygon borders (`clip-path`).
  - Animated 3D cyber grid floor, ambient glow orbs, and retro CRT scanlines.
  - Orbitron, Chakra Petch, Rajdhani, and Fira Code fonts.
- **Top Gamer Telemetry HUD**:
  - Real-time client render **FPS counter** (`requestAnimationFrame`).
  - Fluctuating **Ping indicator** simulating active multiplayer telemetry.
  - HP / Level 21 Game Dev status indicator.
  - **Synthesized Web Audio SFX**: 8-bit blip hover sounds, laser click sounds, and level-up fanfare (mute toggle included).
- **Interactive "Neon Glitch Blaster" Mini-Game**:
  - Playable directly in the hero section!
  - Click or tap moving glitch targets to shoot neon plasma blasts and rack up score & combo multipliers.
- **Character Dossier (About)**:
  - RPG Character Sheet with stat gauges.
  - 2 Years intensive JEE preparation analytical background.
  - College: **Newton School of Technology, Hyderabad**.
- **Mission Archives (Projects)**:
  - Custom Games & Prototypes (Unity, C#)
  - DIMORA — Architectural AI (Python, FastAPI, Three.js, OpenCV)
  - S&AI Practice Arena (Next.js, Tailwind, CLI Shell)
  - FitLife Fitness Experience (HTML5, CSS Animations)
  - Active Semiconductor Phone Cooler (Hardware & Thermals)
  - AI Design Architectures (System Design, Prompt Pipelines)
  - Filter by category: `[ALL MISSIONS]`, `[GAME DEV]`, `[AI & 3D]`, `[HARDWARE & TOOLS]`.
- **Technical Arsenal (Skills)**:
  - Talent tree with animated skill level progress bars.
- **Achievements System**:
  - Floating unlock notification banners that trigger as visitors explore sections and play the mini-game.

## 📁 File Structure

- `index.html`: Complete standalone file ready to open in any browser or deploy.
- `css/style.css`: Modular stylesheet.
- `js/main.js`: Modular audio synthesizer, crosshair, telemetry, and mini-game engine.

## ⚡ Quick Start

Simply double-click `index.html` to open it in Google Chrome, Safari, Edge, or Firefox. No external servers or libraries are required!
